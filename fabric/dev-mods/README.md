# Drop-in development mods

Easy NPC Core and Config UI 7.12.1 are already pinned in Gradle. Do not add duplicate copies here. See [Easy NPC integration](../../docs/easy-npc-integration.md) for editor access, supported behavior configuration and the Forge development manifest workaround.
